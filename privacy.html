Privacy Policy

Last updated: June 3, 2026 · NeatRow Exports by Solace Signal Labs

1. What We Collect

NeatRow Exports collects and stores only the operational data necessary to generate and deliver your order exports:

  • Order metadata: Order ID, display order name, creation timestamp, processing timestamp, financial status, fulfillment status, currency, financial totals (subtotal, discounts, tax, shipping, total price), line item aggregates (counts, SKUs, titles, quantities), tags, shipping destination (country, province, city), and referring site URL.
  • Shopify OAuth session tokens: Securely stored in our database, strictly scoped per store, for API authorization.
  • Export templates & run history: Template names, run timestamps, status, row counts, and temporary file keys.

2. What We Do NOT Collect

NeatRow Exports is designed privacy-first:

  • Customer Personal Information (PII): We do not request the read_customers scope. Customer names, customer emails, and customer IDs are exported as blank strings.
  • Payment Details: We never access or store credit cards, bank accounts, or billing credentials.
  • Data Selling: We never sell, monetize, or share merchant or customer data with third parties.

3. Cloud Storage & File Retention

Generated CSV export files are stored in Cloudflare R2 object storage. Files are accessible exclusively through temporary, time-limited signed URLs and are automatically deleted after 14 days.

Export run metadata (row counts and timestamps) is retained until you delete the template or uninstall the app.

4. GDPR & Data Deletion Compliance

NeatRow Exports is fully compliant with Shopify's mandatory GDPR webhooks:

  • app/uninstalled: Stored store OAuth sessions are wiped immediately upon app uninstallation.
  • customers/data_request: Acknowledged HTTP 200 OK (no customer PII is stored).
  • customers/redact: Acknowledged HTTP 200 OK (no customer PII is stored).
  • shop/redact: All store records, templates, run logs, and associated files are purged within 48 hours.
